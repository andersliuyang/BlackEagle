Chrome / Edge Offline Installation (ZIP)

No store required—download gild.zip, extract it, and load the unpacked extension in your browser.

Download gild.zip Back to Home

Chrome Installation Steps (ZIP)

  1. Download and extract gild.zip to any local folder.
  2. Open chrome://extensions in the address bar and enable "Developer mode".
  3. Click "Load unpacked" and select the extracted folder.
  4. After loading, pin the Gild icon to the browser toolbar to use it.

Updating to a new version

Download the new ZIP, extract to a new folder, remove the old version on the extensions page, then load the new unpacked extension.

Edge Installation Steps (ZIP)

  1. Download and extract gild.zip.
  2. Open edge://extensions and enable "Developer mode".
  3. Click "Load unpacked" and choose the extracted folder.
  4. After installation, pin Gild to the toolbar for quick access.

Common issues

  • Can't load? Make sure you selected the root of the extracted folder.
  • Button is disabled? Ensure "Developer mode" is enabled.
  • Version conflict after upgrade? Remove the old version first, then load the new folder.

Quick checklist

ZIP has been extracted locally, and you selected the extracted folder.

Developer mode is enabled on the browser extensions page.

After installation, enter your LLM Endpoint + API Key in settings to complete configuration.
